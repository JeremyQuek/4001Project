# Review surface

Operate mode: a research worksheet used on a laptop for sustained image review.
The image and statement lead. Use a light neutral canvas, dark ink, restrained
green for approval, amber for partial eligibility, and neutral red for set-aside.
Use the installed Windows UI face for an ordinary local utility, explicit text
labels, keyboard shortcuts, visible focus, and predictable navigation.

Desktop: image on the left, statement/transformations/decision form on the right.
Narrow screens: stack image first, then review form. Progress and save state remain
visible. No decorative imagery, animations, scores or model-output hints.
