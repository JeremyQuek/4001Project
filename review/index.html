Review guide — read this before starting

Check each statement

  1. Find both named objects. Check the supplied True/False label against the original image.
  2. Read the converse: objects and relation are reversed. It should have the same truth as the original.
  3. Compare the mirrored image with its statement. Left/right swap; above/below stay unchanged.
  4. Check that the exclusive statement describes a genuinely incompatible relation between the same objects.

Use the same criteria throughout

For left/right, check the viewer’s perspective. If only an object’s own perspective makes the source label sensible, choose Original only when the original is otherwise usable.

A false original does not make its opposite true. Do not change source labels. Set aside disputed labels, missing objects or unclear relations.

Use Approve all checks only when the original and proposed transformations are suitable. Model predictions and earlier agent flags are hidden.
